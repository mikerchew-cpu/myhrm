# Recruitment & ATS — Hiring Process Guide

**Department:** Recruitment

---

## Overview

This guide covers the end-to-end recruitment and hiring process, from job posting through onboarding and probation, designed to be used with an Applicant Tracking System (ATS) or manual process.

---

## 1. Job Posting

### Creating a Job Description

| Field | Description |
|---|---|
| **Job title** | Standardised title aligned with company job framework |
| **Department** | Functional department |
| **Location** | Office location / remote / hybrid |
| **Employment type** | Permanent, contract (fixed-term), internship, part-time |
| **Salary range** | Budgeted monthly salary range |
| **Role description** | 3–5 bullet points summarising the role |
| **Key responsibilities** | 5–10 bullet points covering core duties |
| **Requirements** | Education, experience, skills, certifications |
| **Preferred qualifications** | Nice-to-have (differentiated from must-haves) |
| **Closing date** | Date when applications close (or "open until filled") |
| **Hiring manager** | Person overseeing the recruitment |

### Job Posting Workflow

```
Hiring Manager submits JD to HR
           ↓
HR reviews and validates (budget, headcount, job grade)
           ↓
HR or TA composes job ad (ATS-generated or custom)
           ↓
Approval workflow (HR Manager → Department Head)
           ↓
Job published to selected channels
```

### Channels for Posting

| Channel | Best For |
|---|---|
| **LinkedIn** | Professionals, executives, specialists |
| **JobStreet** | General roles across all levels (dominant in Malaysia) |
| **Hiredly** | Mid-level to senior, tech, and startups |
| **Indeed** | High volume, entry-level to mid-level |
| **Company career page** | Direct applicants, employer branding |
| **Referrals** | Trusted, culturally fit candidates |
| **Recruitment agencies** | Specialist/hard-to-fill roles |
| **Social media** | Employer branding, passive candidates |
| **Job fairs / campus** | Fresh graduates, interns |

## 3. Applicant Pipeline Stages

The standard pipeline in the ATS consists of the following stages:

### Stage Descriptions

| Stage | Description |
|---|---|
| **New** | Application received; no action taken yet |
| **Screening** | Resumes reviewed; initial pass/fail |
| **Shortlisted** | Passed screening; selected for interview |
| **Interview** | In the interview process (can have sub-stages) |
| **Offer** | Verbal or written offer extended |
| **Hired** | Offer accepted; onboarding initiated |
| **Rejected** | Candidate not moving forward at any stage |
| **Withdrawn** | Candidate withdrew application |

### Stage Sub-Categorisation (Optional)

- **Interview Stage 1:** HR Screening Call
- **Interview Stage 2:** Hiring Manager Interview
- **Interview Stage 3:** Final Interview / Panel

### Pipeline Flow

```
New → Screening → Shortlisted → Interview → Offer → Hired
  ↓         ↓           ↓            ↓          ↓        ↓
  Rejected at any stage
```

## 4. Screening & Assessment

### Resume Screening

| Criteria | Weight (1–5) |
|---|---|
| Relevant experience | 5 |
| Education / certifications | 3 |
| Technical skills match | 4 |
| Soft skills indication | 3 |
| Stability (tenure pattern) | 2 |

### Phone Screen (HR Screening)

Duration: 15–30 minutes.

| Question Area | Purpose |
|---|---|
| Current role and responsibilities | Confirm resume accuracy |
| Reason for leaving | Motivation, red flags |
| Salary expectation | Budget alignment |
| Notice period | Availability |
| Work authorisation | Malaysian citizen / PR / permit holder |
| Cultural fit | Values, work style |

### Skills Assessment

| Type | Examples |
|---|---|
| Technical test | Coding test, writing test, design portfolio review |
| Psychometric test | Personality, cognitive ability |
| Case study | Problem-solving, business acumen |
| Presentation | Industry or role-specific topic |

### Candidate Rating

| Score | Label | Description |
|---|---|---|
| 5 | Excellent | Strongly recommend; top 5% of candidates |
| 4 | Good | Recommend; exceeds requirements |
| 3 | Average | Meets requirements; neutral |
| 2 | Below average | Some concerns; cautious |
| 1 | Poor | Does not meet minimum requirements |

## 5. Interview Process

### Typical Interview Stages

| Round | Interviewer | Focus |
|---|---|---|
| **Round 1: HR Screen** | Recruiter / HR | Motivation, salary, availability, background |
| **Round 2: Hiring Manager** | Reporting manager | Technical skills, experience, team fit |
| **Round 3: Final** | Senior leader / Panel | Strategic fit, culture, decision-making |

### Mode Options

| Mode | Best For |
|---|---|
| **Video call** | Most roles — flexible, efficient |
| **In-person** | Final round, hands-on assessment |
| **Phone** | Initial screen (if video not available) |

### Panel Interview Guidelines

- Limit panel to 3–4 interviewers.
- Assign specific focus areas per interviewer.
- Panel lead coordinates questioning and debrief.
- Score independently before discussion.

### Interview Scorecard

| Competency | Weight (%) | Score (1–5) | Notes |
|---|---|---|---|
| Technical expertise | 30 | | |
| Communication | 20 | | |
| Problem-solving | 20 | | |
| Team collaboration | 15 | | |
| Culture fit | 15 | | |
| **Total** | **100** | **Weighted score** | |

## 6. Offer Process

### Verbal Offer

1. Hiring Manager or HR extends verbal offer by phone/video.
2. Discuss salary, start date, and key terms.
3. Candidate accepts verbally.

### Salary Negotiation

- Negotiate within the approved salary band.
- If above band, require re-approval from HR Head / CEO.
- Consider total compensation (base, bonus, allowances, benefits).

### Written Offer Letter

Must include:

| Component | Details |
|---|---|
| Job title | As per JD |
| Reporting to | Manager's name and title |
| Start date | DD/MM/YYYY |
| Salary (basic) | Monthly amount in RM |
| Allowances | Travel, phone, housing (if any) |
| Bonus structure | Guaranteed / discretionary / target |
| Probation period | Typically 3 months (range 3–6) |
| Notice period | During probie and after confirmation |
| Benefits | Leave, medical, insurance, EPF, SOCSO, EIS |
| Special terms | Bonds (if any), non-compete, IP clauses |

### Offer Letter Approval Workflow

```
HR drafts offer letter
           ↓
Hiring Manager reviews
           ↓
HR Head / Compensation approves (if above band)
           ↓
Offer letter issued to candidate (via ATS/email)
           ↓
Candidate signs and returns
```

## 7. Onboarding

### Pre-Onboarding (Before Day 1)

| Task | Responsible |
|---|---|
| Send onboarding email (welcome, schedule, documents) | HR |
| Request documents (IC, certs, previous payslips, passport photo) | HR |
| Open HR system / payroll profile | HR / IT |
| Request IT equipment (laptop, monitor, phone, access cards) | IT |
| Register for EPF, SOCSO, EIS | HR |
| Arrange desk / workspace | Office Admin |
| Set up email and system access | IT |

### Day 1 — Orientation

| Time | Activity |
|---|---|
| 9:00 AM | Welcome briefing (HR) |
| 9:30 AM | Office tour, introduce to team |
| 10:00 AM | Employment contract signing |
| 10:30 AM | IT setup and system orientation |
| 11:00 AM | Benefits briefing (medical, leave, claims) |
| 12:00 PM | Lunch with team / buddy |
| 1:00 PM | Department-specific onboarding (manager) |
| 3:00 PM | Training schedule review |
| 4:00 PM | Q&A, complete paperwork |

### First Week Checklist

- Complete HR induction form.
- Set up HRDF, payroll, and leave system.
- Meet with key stakeholders.
- Review company handbook and policies.
- Set up 30–60–90 day goals with manager.

## 8. Probation Period

### Duration

- **Standard:** 3 months
- **Extended:** Up to 6 months (for senior roles or performance concerns)
- **Extension:** Manager may extend by 1–3 months if performance not yet confirmed

### Probation Review Process

```
Manager conducts mid-probation check-in (6 weeks)
           ↓
Manager completes probation assessment form
           ↓
Self-assessment by employee
           ↓
Manager–employee discussion (strengths, gaps, confirmation decision)
           ↓
HR reviews and processes confirmation
```

### Confirmation Criteria

| Criteria | Weight |
|---|---|
| Performance against 30–60–90 day goals | 40% |
| Quality of work | 20% |
| Attendance and punctuality | 10% |
| Team collaboration | 10% |
| Adherence to company values | 10% |
| Independence and initiative | 10% |

### Outcomes

| Decision | Action |
|---|---|
| Confirmed | Increase salary (if applicable), issue confirmation letter |
| Extended probation | Document reasons; set new milestones |
| Terminated | Follow Employment Act notice requirement (1–2 weeks during probation) |

### Notice Period During Probation

- Typically **1–2 weeks** (or as per contract).
- Either party may terminate without reason during probation (subject to contract terms).

## 9. Record Keeping

### Retention Requirements

| Document | Retention Period |
|---|---|
| Job descriptions | 6 years |
| Interview notes and scorecards | 6 years |
| Assessment results | 6 years |
| Offer letters | Duration of employment + 6 years |
| Employment contracts | Duration of employment + 6 years |
| Onboarding documents | Duration of employment + 6 years |
| Probation assessments | Duration of employment + 6 years |

### ATS Data Management

- Ensure all candidate data is stored in the ATS.
- Comply with **Personal Data Protection Act (PDPA) 2010** — obtain consent for data processing.
- Purge data of rejected candidates after 12 months (or per company policy).

## 10. Compliance & Fair Hiring

### Legal Requirements

| Requirement | Reference |
|---|---|
| No discrimination in hiring (race, religion, gender, age, disability) | Employment Act 1955, Federal Constitution |
| Fair hiring practices | Industrial Relations Act 1967 |
| Data protection in recruitment | Personal Data Protection Act 2010 |
| Employment of foreign workers | Immigration Act 1959/63 |
| Minimum wage compliance | Minimum Wages Order 2024 |

### Best Practices

- Maintain a **standardised interview scorecard** for all candidates for the same role.
- Document reasons for rejection in the ATS.
- Avoid questions about age, marital status, pregnancy, religion, or political affiliation.
- Provide interview feedback to candidates (at least for shortlisted ones).
