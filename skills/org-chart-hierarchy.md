# Organisation Chart & Approval Matrix

**Department:** General

---

## Org Chart Structure

The organisation chart reflects the company's hierarchical structure and reporting lines.

### Standard Hierarchy

```
Level 1 ──── CEO / Managing Director
                │
Level 2 ──── Directors / C-Suite (CFO, CTO, COO)
                │
Level 3 ──── Managers / Senior Managers (Department Heads)
                │
Level 4 ──── Supervisors / Team Leads
                │
Level 5 ──── Staff / Executives / Associates
```

### Department-Based Grouping

Departments are grouped under their respective Director or Head:
- **Operations** — Warehouse, logistics, production
- **Finance** — Accounting, payroll, treasury
- **HR** — Talent acquisition, L&D, payroll
- **Sales & Marketing** — Business development, advertising
- **IT / Tech** — Engineering, product, infrastructure
- **Legal & Compliance** — Legal advisory, governance

## Reporting Lines

### Solid Reporting (Direct)
- Every employee has **one** direct manager
- Direct manager is responsible for:
  - Performance reviews
  - Leave approval (within authority limits)
  - Career development
  - Day-to-day supervision

### Dotted Reporting (Matrix)
- Common in cross-functional and project-based organisations
- Employee reports to functional manager (solid) **and** project manager (dotted)
- Dotted line = project oversight, but not performance evaluation
- Used extensively in tech companies, MNCs, and consulting firms

### Special Cases
| Scenario | Reporting |
|----------|-----------|
| Intern | Supervisor + HR (dotted) |
| Contract worker | Hiring manager |
| Regional role | Local manager + regional head (dotted) |
| Shared service | Functional head (solid) + site lead (dotted) |

## Levels

| Level | Title | Typical Roles | Board Approval |
|-------|-------|---------------|----------------|
| **L1** | CEO / MD | Chief Executive Officer, Managing Director | Board of Directors |
| **L2** | Director / C-Suite | CFO, CTO, COO, HR Director, Sales Director | CEO |
| **L3** | Manager / Senior Manager | Finance Manager, HR Manager, Operations Manager | Director |
| **L4** | Supervisor / Team Lead | Team Lead, Shift Supervisor, Assistant Manager | Manager |
| **L5** | Staff | Executive, Associate, Clerk, Technician | Manager/Supervisor |

## Approval Matrix

### Leave Approval

| Leave Duration | Approver(s) |
|----------------|-------------|
| ≤ 3 days | Supervisor (L4) → Manager (L3) |
| 4–5 days | Supervisor (L4) → Manager (L3) → Director (L2) |
| > 5 days | Supervisor (L4) → Manager (L3) → Director (L2) → CEO (L1) |
| Medical leave (≥ 4 days) | Supervisor + HR |

### Claim Approval

| Amount | Approver(s) |
|--------|-------------|
| < RM500 | Manager (L3) |
| RM500 – RM2,000 | Manager (L3) → Director (L2) |
| > RM2,000 | Manager (L3) → Director (L2) → CEO (L1) |

### Overtime (OT) Approval

| Condition | Approver |
|-----------|----------|
| ≤ 20 hours/month | Supervisor (L4) |
| > 20 hours/month | Manager (L3) |
| Public holiday OT | Manager (L3) → Director (L2) |
| OT for L3+ employees | Director (L2) |

### Expense Approval

| Category | Amount | Approver |
|----------|--------|----------|
| Departmental OPEX | < RM1,000 | Manager (L3) |
| Departmental OPEX | RM1,000 – RM5,000 | Director (L2) |
| Departmental OPEX | > RM5,000 | CEO (L1) |
| Capital expenditure | Any amount > RM5,000 | Director (L2) → CEO (L1) |
| Travel & entertainment | Any | Manager (L3) |

### Recruitment Approval

| Scenario | Approver(s) |
|----------|-------------|
| New headcount (new role) | Director (L2) → CEO (L1) |
| Replacement (existing role) | Manager (L3) → Director (L2) |
| Temporary / intern | Manager (L3) |
| Contract extension | Manager (L3) → HR |
| Promotion (within level) | Manager (L3) |
| Promotion (cross-level) | Director (L2) → CEO (L1) |

### Purchase / Procurement Approval

| Amount | Approver |
|--------|----------|
| < RM2,000 | Budget holder / Manager (L3) |
| RM2,000 – RM5,000 | Director (L2) |
| > RM5,000 | CEO (L1) |
| IT equipment | Manager (L3) + IT approval |
| Training programme | Manager (L3) + HR |

## Matrix Organisation

### When It Applies
- **Tech companies** — Engineers report to functional lead (solid) and project manager (dotted)
- **MNCs** — Regional matrix: country head (solid) + global function head (dotted)
- **Consulting** — Consultant reports to practice lead (solid) + engagement manager (dotted)
- **Shared services** — Service centre reports to local site lead (dotted) + functional head (solid)

### Key Rules
- One solid line manager per employee
- Dotted line managers can assign work but not perform annual reviews
- Conflicts between solid and dotted managers escalated to L2

## Updating the Org Chart

| Trigger | Action | Owner |
|---------|--------|-------|
| New hire | Add employee to org chart | HR |
| Role change | Update title, level, manager | HR + Manager |
| Department change | Move employee to new department | HR |
| Promotion | Update level and approval authority | HR + Director |
| Resignation | Remove or mark as inactive | HR |
| New department | Create new department node | CEO |
| Reorganisation | Full org chart restructure | CEO + HR |

### Review Cadence
- **Quarterly** — Verify accuracy of all reporting lines
- **Annually** — Full org chart review before performance cycle
- **On change** — Update immediately when role or reporting changes

### Communication
- Org chart updates communicated to:
  - Affected employees (directly)
  - Department heads
  - All managers (for team-level changes)
  - Company-wide (for department or leadership changes)
