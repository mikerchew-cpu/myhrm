### Performance & Development
- Performance appraisal forms
- Key Performance Indicator (KPI) sheets

### Medical & Leave Documents

- Hospitalisation reports
- Maternity leave supporting documents
- Paternity leave records
- Unpaid leave applications
- Extended sick leave reports

## Security & Access Controls

### Confidentiality
- All HR documents are confidential by default
- Disclosure only on a need-to-know basis
- PDPA 2010 compliance strictly enforced

### Role-Based Access

| Role | Access Level |
|------|-------------|
| Employee | Own records only (contract, payslip, profile) |
| Manager | Own team records (performance, leave), no financial/medical |
| HR Staff | Full HR records, excluding director-level documents |
| HR Manager | All documents including sensitive |
| Finance | Payroll and statutory records only |
| Director/CEO | All documents (audit trail) |
| System Admin | Technical access only (no document content) |

### Storage Requirements

| Format | Requirements |
|--------|-------------|
| **Digital** | Encrypted at rest and in transit; cloud backup daily; access logging |
| **Physical** | Locked filing cabinets; restricted room access; sign-out register |

## Digitalisation

- Scan all physical documents to PDF (minimum 300 DPI)
- OCR processing for full-text search capability
- Store in HRIS document management module
- Cloud backup with geo-redundancy
- Document naming convention: `[EmployeeID]_[DocType]_[Date].pdf`
- Version control for updated documents (policy amendments, contract renewals)

### Recommended Digitalisation Workflow

1. Collect original physical document
2. Scan with HR scanner (high resolution)
3. OCR process for searchability
4. Upload to HRIS with metadata (employee ID, document type, date)
5. Store physical document in fireproof cabinet
6. Return original to employee if applicable

## Compliance — Personal Data Protection Act (PDPA) 2010

| Requirement | Action |
|-------------|--------|
| Consent | Obtain written consent to process personal data |
| Notice | Provide PDPA notice at data collection point |
| Access | Allow employees to access their personal data on request |
| Correction | Enable employees to correct inaccurate data |
| Security | Implement technical and organisational safeguards |
| Retention | Do not retain longer than necessary |
| Transfer | Restrict cross-border data transfers |
| Data breach notification | Notify Personal Data Protection Commissioner |

### PDPA Penalties
- Fine up to RM500,000
- Imprisonment up to 3 years
- Compensation order for damages

## Audit Preparation

### Document Register
Maintain a master document register with:
- Document ID
- Employee name and ID
- Document type and category
- Issue date and expiry date
- Storage location (digital/physical)
- Last reviewed date

### Periodic Audits

| Audit Type | Frequency | Scope |
|------------|-----------|-------|
| Document completeness | Monthly | New hires, missing documents |
| Expiry check | Monthly | Permits, certs, contracts |
| Records retention | Quarterly | Purge expired documents |
| Compliance review | Annually | PDPA, EA, statutory compliance |
| Physical storage | Quarterly | Cabinet lock, register accuracy |

### Annual Compliance Review
1. Review all document types against legal requirements
2. Verify retention schedules are being followed
3. Check access logs for unauthorised access
4. Test backup restoration
5. Update document management policy
6. Document the review for audit evidence
